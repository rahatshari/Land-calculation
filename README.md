# উসমানি ও ইসলামিক ফারায়েজ উত্তরাধিকার বণ্টন এবং ভূমি হিসাব অ্যাপ (Uttoradhikar App)

এটি একটি আধুনিক, মোবাইল-বান্ধব এবং সম্পূর্ণ প্রতিক্রিয়াশীল (Responsive) ওয়েব অ্যাপ্লিকেশন যা বাংলাদেশ সরকারের মুসলিম পারিবারিক আইন অধ্যাদেশ ১৯৬১ (Muslim Family Laws Ordinance, 1961) এবং পবিত্র কুরআনের সূরা নিসা-র উত্তরাধিকার বিধান অনুযায়ী সম্পত্তির ফারায়েজ ও পারিবারিক উত্তরাধিকার বৃক্ষ (Family Tree) হিসাব করে।

## বিশেষ বৈশিষ্ট্যসমূহ:
1. **আঞ্চলিক ভূমির মাপ**: ১ কাঠা = ৩.৩০ শতক (২০ কাঠা = ৬৬ শতক = ১ বিঘা) এবং ১.৬৫ শতক = ১ কাঠা (সরকারি মান) টগল করার সুবিধা।
2. **বহু-প্রজন্ম বৃক্ষ (Multi-Generation Tree)**: মূল স্বত্বাধিকারীর পর ছেলে, মেয়ে, স্ত্রী ও অন্যান্য ওয়ারিশদের একাধিক প্রজন্ম পর্যন্ত ধাপে ধাপে উত্তরাধিকার বণ্টন ও পুনর্বণ্টন।
3. **লাইভ প্রিভিউ ও প্রিন্টযোগ্য সনদ**: তাৎক্ষণিক হিসাব প্রিভিউ এবং ফুলস্ক্রিন ভিউ সহ অফিসিয়াল ফারায়েজ সনদ ও CSV এক্সপোর্ট।
4. **সম্পূর্ণ সুরক্ষিত ও পাসওয়ার্ডমুক্ত**: কোনো লগইন বা পাসওয়ার্ডের ঝামেলা ছাড়াই দ্রুত ব্যবহার উপযোগী।

## লোকাল মেশিনে রান করার নির্দেশিকা (Running Locally):

আপনার কম্পিউটারে গিটহাব থেকে ক্লোন করার পর খুব সহজেই নিচের কমান্ডগুলোর মাধ্যমে এটি রান করতে পারবেন:

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

এরপরে ব্রাউজারে `http://localhost:3000` ভিজিট করুন।

## প্রোডাকশন বিল্ড (Production Build):
```bash
npm run build
npm run preview
```
