# উত্তরাধিকার ও ফারায়েজ হিসাব অ্যাপ (Uttoradhikar & Faraiz Calculator)

এটি একটি আধুনিক, মোবাইল-বান্ধব এবং সম্পূর্ণ প্রতিক্রিয়াশীল (Responsive) ওয়েব অ্যাপ্লিকেশন যা বাংলাদেশ সরকারের মুসলিম পারিবারিক আইন অধ্যাদেশ ১৯৬১ (Muslim Family Laws Ordinance, 1961) এবং পবিত্র কুরআনের বিধান অনুযায়ী সম্পত্তির ফারায়েজ ও পারিবারিক উত্তরাধিকার বৃক্ষ (Family Tree) হিসাব করে।

## বিশেষ বৈশিষ্ট্যসমূহ:
1. **আঞ্চলিক ভূমির মাপ**: ১ কাঠা = ৩.৩০ শতক (২০ কাঠা = ৬৬ শতক = ১ বিঘা) এবং ১.৬৫ শতক = ১ কাঠা (সরকারি মান) টগল করার সুবিধা।
2. **বহু-প্রজন্ম বৃক্ষ (Multi-Generation Tree)**: মূল স্বত্বাধিকারীর পর ছেলে, মেয়ে, স্ত্রী ও অন্যান্য ওয়ারিশদের একাধিক প্রজন্ম পর্যন্ত ধাপে ধাপে উত্তরাধিকার বণ্টন ও পুনর্বণ্টন।
3. **লাইভ প্রিভিউ ও প্রিন্টযোগ্য সনদ**: তাৎক্ষণিক হিসাব প্রিভিউ এবং ফুলস্ক্রিন ভিউ সহ অফিসিয়াল ফারায়েজ সনদ ও CSV এক্সপোর্ট।
4. **সম্পূর্ণ সুরক্ষিত ও পাসওয়ার্ডমুক্ত**: কোনো লগইন বা পাসওয়ার্ডের ঝামেলা ছাড়াই দ্রুত ব্যবহার উপযোগী।

## গিটহাবে আপলোড ও গিটহাব পেজে রান করার নির্দেশিকা (GitHub & GitHub Pages Deployment):

এই প্রজেক্টটি গিটহাবে পুশ করার সাথে সাথেই যেন গিটহাব পেজে (GitHub Pages) কোনো ঝামেলা ছাড়াই রান করে, সেজন্য ইতিমধ্যে এতে **Vite Base Path (`base: './'`)** এবং **GitHub Actions অটো-ডিপ্লয়মেন্ট ওয়ার্কফ্লো (`.github/workflows/deploy.yml`)** যুক্ত করা হয়েছে।

### ধাপ ১: গিটহাবে নতুন রিপোজিটরি তৈরি করুন
১. [GitHub](https://github.com)-এ যান এবং একটি নতুন Public Repository তৈরি করুন (যেমন: `uttoradhikar-app`)।

### ধাপ ২: লোকাল প্রজেক্ট গিটহাবে যুক্ত করুন ও পুশ করুন
টার্মিনালে বা কমান্ড প্রম্পটে নিচের কমান্ডগুলো রান করুন:

```bash
# গিট রিপোজিটরি ইনিশিয়ালাইজ করা না থাকলে (ইতিমধ্যে করা আছে)
git init

# সব ফাইল স্টেজ ও কমিট করুন
git add .
git commit -m "Initial commit for Uttoradhikar App"

# গিটহাব রিপোজিটরির মূল ব্রাঞ্চ সেট করুন (আপনার ইউজারনেম ও রিপোজিটরি নাম দিন)
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/uttoradhikar-app.git

# গিটহাবে পুশ করুন
git push -u origin main
```

### ধাপ ৩: গিটহাব পেজ (GitHub Pages) সক্রিয় করা
১. গিটহাবে আপনার রিপোজিটরির **Settings** ট্যাবে যান।
2. বাম পাশের মেনু থেকে **Pages** এ ক্লিক করুন।
3. **Build and deployment** সেকশনের **Source** ড্রপডাউন থেকে **GitHub Actions** সিলেক্ট করুন।
৪. GitHub Actions স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে বিল্ড করে আপনার সাইট ডিপ্লয় করে দেবে (১-২ মিনিট সময় লাগতে পারে)।
৫. এরপর **Pages** পেজেই আপনার লাইভ অ্যাপের লিংক দেখতে পাবেন (যেমন `https://username.github.io/uttoradhikar-app/`)। লিংকে ক্লিক করলেই অ্যাপটি রান করবে!

## লোকাল মেশিনে রান করার নির্দেশিকা (Running Locally):
